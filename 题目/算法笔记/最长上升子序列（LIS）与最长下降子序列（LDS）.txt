最长上升子序列（LIS）与最长下降子序列（LDS）知识讲解
一、基本概念
子序列：在不改变元素顺序的情况下，从原序列中任意删除一些元素（也可以不删）后形成的新序列。
例如：序列 [3,1,2] 的子序列有 [3], [1], [2], [3,1], [3,2], [1,2], [3,1,2] 等。

最长上升子序列（Longest Increasing Subsequence，LIS）：在一个序列中，找到一个最长的子序列，使得这个子序列中的元素严格递增（后一个元素 > 前一个元素）。
最长下降子序列（Longest Decreasing Subsequence，LDS）：类似地，子序列中的元素严格递减（后一个元素 < 前一个元素）。

例子
序列：[3, 1, 2, 4, 3, 5]
一个上升子序列：[1, 2, 4, 5]，长度 4。它也是该序列的 LIS。
一个下降子序列：[3, 2] 或 [4, 3]，最长长度为 2。

二、动态规划思路（O(n²) 方法）
我们使用动态规划解决 LIS 问题，这是初学者最容易理解的方法。

状态定义
设 dp[i] 表示以第 i 个元素 结尾 的最长上升子序列的长度。
（下标从 0 开始或 1 开始均可，这里以 0 开始）

初始状态
每个元素单独可以成为一个长度为 1 的子序列，所以 dp[i] = 1。

状态转移
对于每个位置 i，我们考察所有在它前面的位置 j（0 ≤ j < i）：
如果 a[j] < a[i]（上升条件），那么以 a[j] 结尾的上升子序列后面可以接上 a[i]，长度变为 dp[j] + 1。
我们取所有满足条件的 j 中最大的那个值，即：
dp[i] = max(dp[i], dp[j] + 1) （其中 j < i 且 a[j] < a[i]）

最终答案
整个序列的 LIS 长度就是 max(dp[0], dp[1], ..., dp[n-1])。

最长下降子序列（LDS）
类似地，只需将上升条件改为 a[j] > a[i]，即：
dp[i] = max(dp[i], dp[j] + 1) （其中 j < i 且 a[j] > a[i]）

三、代码示例（求 LIS 长度）
cpp
#include <iostream>
using namespace std;

int main() {
    int a[] = {3, 1, 2, 4, 3, 5};
    int n = sizeof(a) / sizeof(a[0]);

    int dp[100] = {0};  // 假设序列长度不超过100
    int ans = 0;

    for (int i = 0; i < n; i++) {
        dp[i] = 1;                     // 初始化长度1
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i]) {         // 严格上升
                if (dp[j] + 1 > dp[i])
                    dp[i] = dp[j] + 1;
            }
        }
        if (dp[i] > ans) ans = dp[i];  // 更新答案
    }

    cout << "最长上升子序列长度 = " << ans << endl;
    return 0;
}
练习提示：求 LDS 时只需将 a[j] < a[i] 改为 a[j] > a[i]，其余代码相同。
