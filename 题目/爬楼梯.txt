问题描述
小明要爬一个共有 n 级的楼梯，他每次可以跨 1 级 或者 2 级。问：爬到第 n 级台阶，总共有多少种不同的爬法？
例如：
· 当 n = 1 时，只有 1 种方法：1 步跨上去。
· 当 n = 2 时，有 2 种方法：1+1 或者 直接跨 2 级。
· 当 n = 3 时，有 3 种方法：1+1+1、1+2、2+1。

第一步：思考递推关系
我们设 dp[i] 表示爬到第 i 级台阶的不同方法数。
那么，要到达第 i 级，只能从第 i-1 级跨 1 级上来，或者从第 i-2 级跨 2 级上来。
因此，到达第 i 级的方法数就等于到达第 i-1 级的方法数加上到达第 i-2 级的方法数，即：
dp[i] = dp[i-1] + dp[i-2]
这就是状态转移方程。
边界条件也很容易确定：
· 当 i = 1 时，只有 1 种方法，所以 dp[1] = 1。
· 当 i = 2 时，有 2 种方法，所以 dp[2] = 2。
（也可以定义 dp[0] = 1，表示站在地面只有 1 种方法，然后 dp[1] = 1，这样公式从 i=2 开始也成立。两种方式都可以。）

第二步：直接递归的缺陷
我们马上可以写出一个递归函数：
int climbWays(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    return climbWays(n-1) + climbWays(n-2);
}
这个递归非常直观，但当 n 稍大时（比如 n=40），运行会非常慢，甚至卡死。为什么？因为它会重复计算大量相同的子问题。例如计算 climbWays(5) 时，climbWays(3) 被计算了两次，climbWays(2) 被计算了三次……这种重复计算随着 n 增大呈指数级增长。

第三步：用动态规划优化
动态规划的核心理念就是：用一个数组把已经算过的子问题的结果保存下来，下次需要时直接取用，不再重复计算。
我们可以用两种方式实现：自顶向下的记忆化搜索 和 自底向上的递推。这里先介绍更直观的自底向上递推。
自底向上递推（推荐初学者掌握）
我们从最小的子问题开始，一步一步向上推到我们要求的 n。
步骤：
1. 开一个数组 dp，大小为 n+1（下标从 0 或 1 开始）。
2. 初始化边界：dp[1] = 1, dp[2] = 2（如果 n ≥ 2）。
3. 从 i = 3 循环到 n，依次计算 dp[i] = dp[i-1] + dp[i-2]。
4. 最终答案就是 dp[n]。
代码实现（C++）：
#include <iostream>
using namespace std;
int main() {
    int n;
    cout << "请输入楼梯级数 n：";
    cin >> n;
    // 处理特殊情况
    if (n == 1) {
        cout << "爬到第 " << n << " 级的方法数为：1" << endl;
        return 0;
    }
    if (n == 2) {
        cout << "爬到第 " << n << " 级的方法数为：2" << endl;
        return 0;
    }
    // 定义数组，长度为 n+1，下标从 1 开始使用
    int dp[1000];   // 这里假设 n 不超过 1000，实际可以用 vector 动态分配
    dp[1] = 1;
    dp[2] = 2;
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    cout << "爬到第 " << n << " 级的方法数为：" << dp[n] << endl;

    return 0;
}
运行结果示例：
请输入楼梯级数 n：10
爬到第 10 级的方法数为：89
这个算法的时间复杂度是 O(n)，空间复杂度也是 O(n)，比指数级递归快得多。

第四步：空间优化（滚动数组）
观察上面的递推过程，我们发现计算 dp[i] 时只需要用到 dp[i-1] 和 dp[i-2]，更早的数据就不再需要了。因此，我们可以用两个变量滚动更新，将空间复杂度降到 O(1)。
优化后的代码：
#include <iostream>
using namespace std;
int main() {
    int n;
    cout << "请输入楼梯级数 n：";
    cin >> n;

    if (n == 1) {
        cout << 1 << endl;
        return 0;
    }
    if (n == 2) {
        cout << 2 << endl;
        return 0;
    }

    int a = 1;   // 代表 dp[i-2]
    int b = 2;   // 代表 dp[i-1]
    int c;       // 代表当前 dp[i]

    for (int i = 3; i <= n; i++) {
        c = a + b;
        a = b;    // 向后滚动
        b = c;
    }
    cout << "爬到第 " << n << " 级的方法数为：" << b << endl;
    return 0;
}

总结：动态规划的三大要素
通过这个例子，我们可以提炼出动态规划解题的一般步骤：
1. 定义状态：明确 dp[i] 表示什么。这里 dp[i] 表示爬到第 i 级的方法数。
2. 写出状态转移方程：找到不同状态之间的联系，即 dp[i] = dp[i-1] + dp[i-2]。
3. 确定边界条件：最小的子问题的解是什么，如 dp[1] = 1, dp[2] = 2。
然后，我们就可以用循环（或递归+备忘录）来实现。

扩展思考
爬楼梯问题其实和斐波那契数列非常相似（斐波那契是 f(1)=1, f(2)=1, f(n)=f(n-1)+f(n-2)），只是边界条件略有不同。你还可以尝试解决类似的问题：
· 如果每次可以跨 1、2 或 3 级，怎么修改？
· 如果有些台阶坏了不能踩（带限制的爬楼梯），又该如何处理？
掌握了最简单的动态规划，就能一步步攻克更复杂的 DP 问题，比如背包问题、最长上升子序列等。记住动态规划的精髓：拆分子问题，记录结果，避免重复计算。多练习、多思考，一定能熟练掌握
