## 编译与运行

源码均为单文件程序，用 g++ 直接编译：

```bash
g++ -std=c++14 -O2 "c++代码/动态规划/P2657.cpp" -o "$TEMP/P2657.exe"
```

> **Windows + MinGW 注意**：`ld.exe` 无法正确处理含中文的输出路径，会把 exe 生成成乱码名或直接报错。
> 因此 `-o` 建议指向纯英文路径（如上例的临时目录）；`.vscode/tasks.json` 里的编译任务也是用
> ASCII 临时名再改名的。源码路径含中文没有影响。

文件编码统一为 **UTF-8（无 BOM）**。若在 Windows 下用 PowerShell 5.1 的 `Get-Content` 看到中文乱码，
是控制台默认按 GBK 解码所致，文件本身无问题；可改用 `Get-Content -Encoding UTF8`。

## 版本控制约定

`.gitignore` 排除以下内容，它们只保留在本地：

- `*.exe` / `*.o` / `*.obj` 等编译产物（含 `c++代码/exe编译产物/`）；
- 386 MB 的 `sb3/宝可梦GUI.sb3`（超出 GitHub 单文件 100 MB 限制）；
- `*.rar` 等归档包；
- `.vscode/` 编辑器配置。

**登录凭证不入库**：`py/music_player/config.json` 保存各平台的登录 Cookie，已被忽略且不纳入版本控制，
仓库只提供模板 `py/music_player/config.example.json`。请勿把含真实 Cookie 的配置文件提交上来。
