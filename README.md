## 编译与运行

源码均为单文件程序，用 g++ 直接编译：

```bash
g++ -std=c++14 -O2 "c++代码/基础语法/P1001 A+B Problem.cpp" -o "c++代码/exe编译产物/基础语法/P1001 A+B Problem.exe"
```

文件编码统一为 **UTF-8（无 BOM）**。若在 Windows 下用 PowerShell 5.1 的
`Get-Content` 看到中文乱码，是控制台默认按 GBK 解码所致，文件本身无问题；
可改用 `Get-Content -Encoding UTF8`。
